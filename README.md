🚀 Descripción
Este proyecto ofrece una estructura básica y organizada en Modelo-Vista-Controlador (MVC) para desarrollos en PHP. 

Su objetivo es proporcionar una base sólida que permita a los desarrolladores centrarse en la lógica de negocio, 
reduciendo el tiempo necesario para configurar la estructura de un proyecto desde cero.



🛠 Características
Arquitectura MVC clara y modular.

Preparado para escalar proyectos rápidamente.

Código limpio y fácil de mantener.

Ideal para proyectos personales, profesionales o educativos.
